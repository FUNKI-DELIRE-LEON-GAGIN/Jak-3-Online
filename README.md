# Jak 3 En Ligne (Jak 3 Online)

Mod multijoueur en ligne pour **Jak 3** sur [OpenGOAL](https://opengoal.dev) : un monde en ligne partagé
(Haven City et le désert), boutique en orbes (armes, Dark / Light Jak, armures, style), véhicules à
appeler, boss, courses, 8 parcours, maisons à acheter (cabane, villa, château) où inviter ses amis,
téléportation, personnages jouables (Keira, Jak 2, Jak 1 HD, Jak 4, Tess, Daxter, Ashelin, Torn, Sig, Samos),
8 maisons (jusqu'au palais à 1 000 000 d'orbes) avec boîtes aux lettres qui rapportent chaque jour, vue à la
première personne, collisions entre joueurs (on monte sur la tête des autres), course auto, cache-cache,
météo et dialogues lancés par l'admin, Hellcat volant
pilotable partout, vraies collisions avec les véhicules des autres joueurs (on monte dessus, ils nous
emportent), joueur 2 local (2e fenêtre, 2e manette), coop en session privée, anti-triche, 23 langues.

- `goal_src/jak3/pc/features/online*.gc` : le code du mod dans le jeu (GOAL)
- `online/src/` : Jak3Online.exe, le programme compagnon (réseau, profil, boutique, anti-triche)
- `online/LISEZ-MOI.txt` : le guide du joueur

Il faut ta propre copie de Jak 3 (PS2) : aucun fichier du jeu n'est dans ce dépôt.
